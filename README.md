# 🚀 About UNIVO

**UNIVO** is a student-focused social platform designed to bring university students together in one digital space.

UNIVO is built around the everyday student experience, helping students connect, communicate, learn, discover opportunities and access useful student services.

The platform brings different parts of student life together in one place.

### UNIVO is built for:

- 🎓 University students
- 👥 Student communities
- 🏫 Universities and institutions
- 📚 Academic learning
- 💬 Student communication
- 🛒 Student marketplace activity
- 🏠 Accommodation discovery
- 🤝 Student networking
- 📅 Events and activities

> **Connect • Learn • Grow.**

⚙️ Getting Started
1. Clone the Repository
git clone https://github.com/Botcreationam/REPOSITORY_NAME.git
cd REPOSITORY_NAME

Replace REPOSITORY_NAME with the actual repository name.

2. Install Dependencies
flutter pub get
3. Configure Environment

Configure the environment variables required by the project.

Never commit production secrets.

Example:

API_BASE_URL=YOUR_API_URL
SUPABASE_URL=YOUR_SUPABASE_URL
SUPABASE_ANON_KEY=YOUR_PUBLIC_KEY

Only use values that are safe for the client application.

4. Run the Application
flutter run
📱 Android Development

Check the Flutter environment:

flutter doctor

Check connected devices:

flutter devices

Run the application:

flutter run
📦 Build Android APK

Create a release APK:

flutter build apk --release

The generated APK can normally be found under:

build/app/outputs/flutter-apk/
🏪 Build Android App Bundle

For Google Play distribution:

flutter build appbundle --release

The generated AAB can normally be found under:

build/app/outputs/bundle/release/
